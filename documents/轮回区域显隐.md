# 轮回区域组织与显示层级

## 资源结构

总入口：Client/Assets/GameMain/Art/WorldTimeline/BirthRegion/BirthRegion.prefab。
独立区域：同目录 Regions 下的 8 个 Region_*.prefab。区域对应青篁谷、赤石坡、白溪渡、黑牙巢、洗髓灵泉、古修遗府、林间岔路和山口。
Terrain 继续统一负责高度、地表草地及泥路。原来跨区域的道路覆盖网格已移除。

每个区域有三组可编辑对象：

- Near：灌木、泉边石、碎石、倒木等细节，近景显示。
- Middle：树林、主要山石、关卡地标，近景和中景显示。
- Far：最多 3 个地标剪影对象，远景显示，关闭阴影投射。

远景通过减少对象数简化画面，复用原模型网格及材质，目前没有对单个模型做减面。

## 显示控制

WorldTimelineRegionCulling 位于总入口预制体上，统一计算相机视锥并驱动各 WorldTimelineRegion。
默认地图相机已改为透视投影：俯角 48°、朝向 -20°、垂直 FOV 48°。缩放通过调整相机与焦点的距离实现。
区域根据透视投影后的占屏比例切换，兼容正交投影，但不再默认使用正交地图相机。
默认近景阈值 0.18，中景阈值 0.10；切换缓冲比例 12%，每 0.15 秒更新一次。
视野边缘有额外包围盒余量，离开视野后等待 0.35 秒才隐藏。
切换到主菜单或战斗虚拟相机时，区域装饰关闭；返回地图后重新评估。
节点、连线和角色棋子仍由独立的地图绘制系统显示，不受装饰层级控制。

## 手工编辑

直接编辑 Regions 中的独立预制体。在对应 Near、Middle 或 Far 分组里添加或调整装饰。
修改摆放范围后，在 WorldTimelineRegion 检视面板点击“重新计算区域包围盒”。选中区域时 Scene 视图会显示包围盒。
主要地标形状或位置改变时，也要同步调整 Far 中的剪影对象。
总入口 WorldTimelineRegionCulling 检视面板可调整阈值、边缘余量与延迟；运行时显示各层级区域数和已启用装饰 Renderer 数。

## 批处理选择

重复树木、山石和远景对象共享 Mesh 与 Material，材质已允许 GPU Instancing；实际采用的渲染批处理路径由 URP 决定。
本次移除了整片样板上的 Batching Static 标记，没有自动将重复植被合并成独立网格，避免扩大网格内存。
地标已经按区域独立组织，后续有实测需要时可单独对某块区域的固定建筑进行合批。

## Unity 验证工具

进入轮回地图后：
- Ctrl+Alt+F10：自动验证近景、中景、同相机全细节对照、远景、视野外状态；并检查切换缓冲和边缘延迟。
- Ctrl+Alt+F11：定位到青篁谷样板的近景视角。

验证只移动相机，不提交角色行动、不推进年份。结束后恢复原视角。
统计报告：Tests/WorldTimeline/obj/RegionVisibility/Validation.json。
Draw Call 是 Editor 中整幅 Game 画面的统计，包含地形、UI 和节点，不能等同于区域装饰 Renderer 数。

## 地图透视相机参数

在 BirthRegion.prefab 根节点的 WorldTimelineMapLayout 组件中调整 Camera Pitch、Camera Yaw 和 Camera Field Of View，重新进入轮回后生效。
地图控制仍由 Cinemachine 虚拟相机驱动已有真实主相机，不新增真实地图相机。
拖动通过屏幕射线与焦点水平面的交点计算位移；点选按每个节点的实际投影大小计算，不再共用固定正交半径。
