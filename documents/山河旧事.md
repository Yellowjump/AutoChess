# 山河旧事

## 故事定稿

归墟大阵原本负责疏导灵脉浊气。阵法破损后，守印人开始用活人的名字替代镇物。被征名的人逐渐被亲友遗忘，村庄也从舆图上消失。守印人的女儿是第一批被献入阵中的人。如今守印人准备封尽灵脉，将山河与浊气一起沉入地底。

青禾村的渡船名册记着十二人，船夫数来只有十一人。那个被漏掉的孩子就是天选。他曾被抹名，却活了下来。玩家通过不同修士的行动改写同一条时间线。游戏在关键节点、道具和战后事件里交代因果。

## 关卡与角色

| 地点 | 剧情目标 | 解法 |
| --- | --- | --- |
| 青禾乡野 | 渡船名册出现空行，天选循线前往临溪。 | 开篇事件埋下抹名线索。 |
| 临溪渡口 | 逆流封住水路。 | 让修成《逆潮诀》的沈砚到场，或让天选取得一次性的镇水铃。 |
| 灵山古隘 | 山门按名册查验来者。 | 旧关印开门并保住补给，或让修成《断契剑》的陆缨破门，再打守门战。 |
| 松溪古祠 | 找到被抹去的姓名在阵中的位置。 | 天选读出还名册，或由外坛救出的执笔人辨认被改写的那一页。 |
| 归墟外坛 | 击败守印人。 | 任何修士可挑战。胜者可断祭脉争取时间，或救出执笔人。外围也布置独立的断脉点。 |
| 归墟内坛 | 打开内坛、击败阵主、解除大阵。 | 旧关印或《断契剑》解决门契，还名册或执笔人定位姓名。满足门槛的修士均可挑战。 |

**沈砚**是临溪船夫。他以为从渡船簿上刮去妹妹的名字可以躲过征名。如今每次点人数，他仍会下意识给她留一个位置。原轨迹里他下沉舟寻镇水铃，死于水妖。若有人先清掉水妖，他可从沉舟遗卷学得《逆潮诀》，赶赴渡口与天选会合。替代线由修士取铃并留给天选。

**陆缨**曾替守印人押送祭品，得知货物其实是被抹名的人后偷走关印。原轨迹里她在关外被追兵杀死。追兵提前被击败时，她可去剑冢学得《断契剑》，再追上天选。也可以从她的遗物里取回旧关印。两人的剧情准备都发生在正式入队前，沿用入队后停止成长的规则。

## 内坛胜利与结局

外坛和内坛的首领均有本局共享的攻破状态。前世记录中的胜利要在本局重新发生才生效。阵主一旦被击败，本局不会复活，胜者存活，并可压制阵心争取时间，或离开接应天选。入坛前由执笔人或铭文说明阵主可杀，大阵还要另行解除。

天选抵达已攻破的内坛后，在阵心亲手写回自己的名字，进而归还其余姓名。结局分别记录斩阵主者和解除大阵者。若天选已经死亡，其他修士仍能破坛、压阵和撤离受困者。到仪式截止年按成果结算，例如「斩阵主，未解归墟」。结尾重回渡船，船夫再点一次人数，这次与名册对上。

## 接入范围

首批内容接入青禾旧簿、临溪渡口和沈砚的寻铃线索，借用现有剧情背景。青禾开篇落在当前天选路线的首个抵达节点，临溪保持在现有水墨地标区。后续须统一调整天选路线、会合年份、断脉收益和仪式时限，再启用渡河、开隘和内坛门槛。新终局应与旧存档演算规则区分，旧局续玩沿用其原规则。
