# 归墟阵主 · 无名碑

归墟内坛以活人的姓名补全阵纹。被抹掉的姓名在阵心结成一座会移动的石碑。阵主继续执行守印人留下的最后一道命令，将人名、村名和灵脉一并封存。碑首的裂缝中夹着一页发白的名册，守印人的女儿名列第一，最后一格留给那个从渡船名册上消失的孩子。

> 入坛铭文：请按名入阵。无名者，留在原处。  
> 阵主破碎时：末行仍空。请本人执笔。

从战斗镜头看，六瓣低矮的玄石碑脚围住中央裂碑。朱砂门契横封在碑身，青铜箍扣住裂口，碑背露出一页夹在石缝中的名册。移动时六瓣碑脚随阵心挪动。碑脚对应六个邻格，阵心占中央格。采用低面、低饱和的石材，轮廓和裂口要在俯视镜头中可读。

| 技能 | 表现与玩法 |
| --- | --- |
| 镇名重砸 | 基础近战。碑身后仰蓄力 0.65 秒，砸向当前目标，造成 125% 攻击力伤害。按碑脚的边缘距离判定近战范围，命中时短震。 |
| 封名裁线 | 每第三次常规出招施放。锁定方向并画出朱砂边界，碑身后仰蓄力，再朝裁线拍下。蓄力共 1.05 秒，落碑时结算长 4.4、宽 1.64 个战斗单位的条形区域。每名敌人最多受到一次 115% 攻击力伤害。 |
| 封山归墟 | 阵主半血后，在下一次可攻击时优先施放，每场最多结算一次。先画出半径 2.7 个战斗单位的阵纹，蓄力 1.55 秒后爆发，对圈内敌人造成 155% 攻击力伤害。 |

阵主倒下时留下空白末行。入坛铭文和末行台词留作地图剧情事件文本。
