# 轮回配置表

正式游戏配置统一通过 Game Framework 数据表加载。

| Excel 源表 | 用途 | 数据行类型 |
| --- | --- | --- |
| Config/OuterLocations.xlsx | 节点坐标、名称、修炼收益、守怪和掉落 | DROuterLocations |
| Config/StartingCultivators.xlsx | 固定修士、出生坐标和初始装备 | DRStartingCultivators |
| Config/BattleMapping.xlsx | 天选、守怪、轮回装备对应的自走棋英雄与道具 | DRBattleMapping |
| Config/CultivationLevel.xlsx | 升级经验和各属性资质增量范围 | DRCultivationLevel |

## 修改数值

1. 修改 Config 目录中的 Excel，保留前四行的表结构。
2. Unity 菜单 Tools → Excel To Txt Converter，选中修改的表，点击 Convert Selected Files。工具会导出 txt 并生成 bytes。
3. 退出 Play 后重新进入 bootstrap，让 ProcedurePreload 重新加载数据表。

增加或修改字段时，再执行 Tools → Generate DataTable Code，并更新 WorldTimelineTableConfig 中对应字段的映射。

导出位置：Assets/GameMain/Data/DataTables。数据行代码：Assets/GameMain/Scripts/DataTable。
运行链路：ProcedurePreload 加载 bytes，WorldTimelineTableConfig 提供具名配置，模拟逻辑不依赖 Unity 或 CSV。

Tests/WorldTimeline/Fixtures 中的 CSV 是旧数值的测试快照，不进入游戏构建，也不作为游戏配置来源。独立诊断场景仅在 Unity Editor 中可以读取测试快照。

已有当前局续玩存档按行动记录重演；改变表格数值可能导致旧局校验不一致。核对新配置时请开始新局。
