# 山河旧事 · 第十二个名字

开场从一次普通的渡船点名开始。船夫数到十一便开船，名册留下第十二个位置，孩子留在岸上。先让玩家看见遗忘发生在一个人身上，再揭开归墟征名。片尾回到元年，用渡口的孩子抵达古修石门的时间，让玩家第一次亲手改变这一世的走向。

## 分镜与台词

| 时间 | 画面与剪接 | 台词 | 声音 |
| --- | --- | --- | --- |
| 00–06.4 | 黑场淡开。船夫在渡口点名，末尾划一桨离岸。 | 船夫「十、十一……齐了。」 | 近处水响，低弦拨出两个音。 |
| 06.4–12.8 | 叠化到名册，沿墨迹移到刮白的一栏。 | 「簿上本有十二个名字。最后一个，只剩一道刮痕。」 | 拨弦留下空拍，刮纸声落在空栏。 |
| 12.8–19.2 | 一个连续的肩后镜头。孩子沿栈桥追船，收步后伸手。镜头慢慢拉开，船已经滑向远处。 | 孩子「我还在这儿。」旁白「船离了岸。没有人回头。」 | 水声渐远，气声长音进入。 |
| 19.2–25.6 | 叠化到归墟裂阵，沿朱砂裂隙推近阵心。 | 「归墟大阵破了。守印人拿活人的名字补阵。名字一入阵，亲友便会忘了那个人。」 | 低钟压住拨弦，水声沉下去。 |
| 25.6–32 | 叠化到元年石门，镜头拉开露出两条路。最后半秒淡黑，接元年地图。 | 「第三年，渡口那孩子会走到这里。」「这一回，你也在路上。」 | 高一度的拨弦与气声旋律接回，落在低音主音上。 |

守印人的女儿、沈砚与妹妹、还名和阵主的因果留给地图事件。第一局玩家操控赤砾，片中用「渡口那孩子」指代后来被人叫作「天选」的角色。第三年是古修石门教学里的抵达时间，首局路线选择继续解释残剑和两条路的代价。

## Unity

- `Client/Assets/GameMain/Art/Opening/TheTwelfthName.playable` 是 32 秒 Timeline。五段字幕与两个音轨跟随同一条画面视频，画面每 6.4 秒转换一次，叠化约 0.4 秒。黑场只在片头和片尾。
- `ArtSource/WorldTimeline/OpeningMotion-ferry.blend`、`OpeningMotion-child.blend` 与 `OpeningMotion-gate.blend` 是 Blender 4.1 源场景。可用 `Tools/Blender/build_opening_cinematic.py` 渲染为 `cut-ferry.mp4`、`cut-child.mp4`、`cut-gate.mp4`，再运行 `Tools/WorldTimeline/edit_opening_picture.py` 合成 24 fps 的 H.264 画面。
- `OpeningCinematic.prefab` 已绑定到主菜单。首局符合石门教学条件时播放。主菜单「观看开场」随时可回看，播放完或跳过后回到主菜单。右上角或 Esc 可跳过。字幕随中英文设置切换，配乐与音效读取主音量和相应分组音量。台词以字幕呈现。
- 在 Unity 可用 Tools → World Timeline → Validate Opening Cinematic，通过独立测试存档验证自然结束、跳过和继续游戏。
- `Tools/WorldTimeline/compose_opening.py` 生成原创配乐《第十二个名字》和环境声两份 WAV。拨弦、气声与低钟为合成音色。
