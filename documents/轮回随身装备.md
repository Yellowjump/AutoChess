# 随身装备

地图底部角色操作面板中，原“修行资质”位置拆为“修行”和“装备”。点击“装备”打开独立的 Game Framework tips 层原生 UGUI 预制体：

`Client/Assets/GameMain/Prefeb/UIPrefab/world_timeline_inventory.prefab`

左侧显示当前本世修士的真实头像、境界、当前/最大气血、基础攻击和含功法加成的战斗攻击。中间为全部、兵器、遗物、功法分类，每页12种物品；右侧点击查看名称、说明、来源与持有数量。同ID合并显示数量，底层实例保留，不受格数限制。仅显示实际持有数据，不以参考图中的演示物品填充。

当前轮回获得的装备与功法自动生效，界面负责查看，没有新增穿脱、丢弃或合成行为。打开时暂停自动观察，关闭后按之前的观察状态恢复；点击界面不会穿透到地图或消耗年份。身死后的持有物品仍可查看。

## 数量限制

旧 `HeroComponent.SelfData.TryEquipItem` 的 `EquipItemList.Count >= 5` 限制已移除。轮回 `ActorState.Items` 和原生 `EntityQizi.AddInitItemFromList` 本来就遍历全部实例，没有六件截断。

保留合法性检查：目标角色存在，装备实例必须真的在背包内；同一实例不能重复装备。装备排序、技能重建和属性计算仍沿用原来的逻辑。不会通过放大一个固定上限来模拟“无限”。

## 文件与美术

- `WorldTimelineDebugView.Inventory.cs`：从当前会话、初始修士、剧情道具、关卡掉落配置解析名称、分类与说明。
- `WorldTimelineInventoryCtrl.cs`：只绑定预制体，负责分类、分页、详情和状态刷新。
- `WorldTimelineInventoryAuthoring.cs`：编辑器菜单 Tools → World Timeline → Build Inventory Prefab，生成预制体并安装地图入口；重新执行会覆盖界面布局。
- `Image/WorldTimeline/Inventory/item_icons.png`：独立16图标图集，原生 Sprite 切片，未把名字和边框烘焙进图标。
- 参考图、提示词：`ArtSource/UI/inventory-reference.png`、`inventory-prompts.md`。均使用内置 image_gen，风格参考现有 cultivation_ui_atlas。

## 验证

运行 bootstrap 并停在主菜单后，Tools → World Timeline → Validate Inventory Flow。使用独立临时轮回存档，原生装备测试也会清理临时角色和装备并恢复唯一ID计数，不修改用户现有角色。

验证包括实际给原生角色装20件武器并检查20个技能实例、拒绝重复实例、地图入口、空分类、剧情获取物品后的详情、43种物品跨四页、重复数量、关闭恢复地图、续玩后的装备恢复。报告位于 `Tests/WorldTimeline/obj/Inventory/<时间>/Validation.json`。

发布时新预制体和图集仍需纳入工程原有资源打包流程。

打开背包时隐藏地图顶部与地图操作区，关闭后恢复，避免独立 Canvas 排序遮挡“返回山河”。2026-11-05 在 Unity Play 模式通过23项检查，报告及实际截图位于 `Tests/WorldTimeline/obj/Inventory/20261105-200119/`。
