# 水墨山河样板区

## 已接入的山河分区

独立平面地图，目前挂在 `Client/Assets/GameMain/Scenes/terrain.unity` 的 `InkMapSample` 根预制体实例。这个场景名只是原有启动流程的宿主：地图不查找 Terrain，不读取地形大小，不做地形/碰撞体高度采样。主菜单与战斗沿用原场景；地图进入时切换专用图层，退出时恢复主相机设置。

- 总预制体：`Client/Assets/GameMain/Art/WorldTimeline/InkMap/InkMapSample.prefab`。
- 外围：`InkMap/Regions/Outer_青禾乡野.prefab`，锚点 `(0,-9)`。
- 过渡：`InkMap/Regions/Transition_灵山古隘.prefab`，锚点 `(0,-6)`。
- 两种透明水墨底景独立保存为 `OuterCountryside.png`、`InnerPass.png`；内置 image_gen 生成，提示词保存在 `ArtSource/WorldTimeline/ink-region-prompts.md`。
- 当前扩成18个独立区块（9个外围乡野、9个内向过渡区域），覆盖十个修士出生点附近的主要视野。区域尺寸从6.2×5.2个间距扩大为8.8×7.6个间距，底景铺设面积约为原来的2.1倍。世界中心仍留给后续禁地、Boss区域设计，不代表整张地图美术已经完成。
- 新增 `InkMap/LandmarkAtlas.png`，由内置 image_gen 生成村落、渡口、山门、古祠四种地标；提示词位于 `ArtSource/WorldTimeline/ink-landmark-atlas-prompt.md`。以四个材质UV区域复用同一图集，每个区块分别放置一个3.4×3.1间距的主地标，普通缩放下即可辨识。
- 普通节点圆环变小、变淡，普通连线宽度减半、透明度降低；可走路径、选中节点和存活角色所在节点保持突出。默认定位缩放从0.45调整为0.31，可在布局组件的 `FocusZoom` 修改。
- 节点保持原有坐标、331节点及六边形邻接。`WorldTimelineMapLayout.Project` 统一使用原点、节点间距、六边形坐标投影；节点与棋子在固定平面上定位。无布局配置会明确报告初始化失败，不回退寻找地形。
- 宣纸地表与区域墨迹使用普通 MeshRenderer 和 `SRPDefaultUnlit` Shader，由 URP 透明物体通道正常绘制。可直接在 Scene 中查看、移动和编辑。`WorldTimelineRenderFeature` 只绘制节点、连线、棋子，不清除底景、不画水墨贴图。
- 地图 Renderer 仅在地图打开期间显示，进入可视战斗或退出地图时隐藏，避免遮住原场景。分区 Near/Middle/Far 显隐继续单独生效。
- 地图组件复用已有 `WorldTimelineRegionCulling` 做区域显隐；当前 Far 复用同一底景贴图，后续需要时可替换为简化轮廓。

构建菜单：Tools → World Timeline → Build Ink Map Sample（停止 Play 后）。重新构建会更新18个区域预制体和它们的总实例，手动摆放前请先复制独立版本。区域列表和尺寸统一声明在 `WorldTimelineInkMapAuthoring.cs`。

本次未控制Unity界面，已通过 `Tools/WorldTimeline/expand_ink_map.py` 直接烘焙并更新实际预制体。该脚本读取同一份C#区域声明，保留已有GUID和总预制体根ID；`python Tools/WorldTimeline/expand_ink_map.py --check` 校验确定性输出、本地引用完整性和十个出生点的底景覆盖。

渲染数量上限为宣纸1个、每可见区块底景及地标各1个；18区全部可见时最多37个普通Scenery Renderer，日常视角由分区裁剪减少。Near/Middle/Far各层的共享图集不会重复加载，Far和Middle互斥；此数量不是整帧Draw Call实测值。尚未进行这版Unity实机视觉和性能检查。

验证菜单：运行 bootstrap 主菜单后 Tools → World Timeline → Validate Ink Map Sample。使用临时存档；报告、实际截图保存在 `Tests/WorldTimeline/obj/InkMap/<时间>/`。检查包含原节点、分块、平面点击、实际灰墨画面及离开后的相机图层恢复。

相机设置由 `WorldTimelineBoard` 的生命周期持有：初始化进入地图、禁用/销毁退出。`WorldTimelineInkMap` 不订阅渲染事件、不在 Update/LateUpdate 轮询，也不查询 Cinemachine 的 ActiveVirtualCamera。`WorldTimelineBattleResolver` 仅在可视战斗期间使用可释放的暂停作用域恢复场景设置，结束或异常清理时归还地图表现；后台战斗不暂停。重复渲染查询没有相机写入副作用。该修复已通过核心代码编译，新增的相机生命周期回归项尚待 Unity 实机执行。

## 美术目标

当前方向以第三版为准：ArtSource/UI/ink-world-map-reference-v3.png。主体只用黑、灰、浅宣纸白，取消多色灵气光流与大面积金色；极少量低饱和强调色仅服务选中状态和角色识别。概念图用于展示密度与风格，不作为地图坐标或连通数据。

### 节点密度与分块

- 保留现有331节点的规模，概念图显示的点数不构成削减地图的要求。普通节点用小点/细环，重要节点使用地标；名称按缩放及选择状态显示，避免每点都放大铭牌。
- 远景收敛普通点与文字，近景展开局部节点与连线。所有存活角色保留可辨识的位置标记。
- 地图按六边形坐标归属划分区块，逻辑节点ID保持稳定，区块只组织资源与局部内容，不强行改变六边形连通规则。
- 每块分别维护装饰预制体、地表水墨素材、地标锚点和框架表中的关卡配置。装饰淡出至纸白，边界无硬拼接线。
- 节点、道路、文字、棋子单独渲染，绝不烘焙进整张背景。跨区道路依据节点邻接绘制，河道等跨区景观约定接口位置。
- 修改剧情/奖励只改表；修改地标只改本区预制体；移动或增删节点需要同步处理邻接、旧历史路线和存档兼容，分块本身不能消除数据迁移问题。
- 先做一个外围样板块及相邻的内向过渡块，验证无缝拼接、浓淡变化和跨区移动，再扩展全图。

第二版参考：ArtSource/UI/ink-world-map-reference-v2.png。区域强度依据到世界中心的距离总体递增，而非屏幕上下位置。外围以平和村落、田野、疏林和缓丘为主；中圈以宗门、灵山、妖林体现更高灵气和风险；内圈集中禁地、强大魔物与仪式遗迹。高灵气不等于魔气，保留清灵险境和受污染区域的区别。出生区少量危险节点只应是相对外围的低强度遭遇，旧草案的“幽冥洞”等危险意象应移入更深区域。图中节点名、数量及线路仅为概念展示。

参考图：ArtSource/UI/ink-world-map-reference-v1.png。这是 AI 概念图，不是 Unity 实机截图。使用内置 image_gen 生成，现有背包截图仅作为宣纸、青墨、暗金风格参考。

保留三维节点与棋子交互，表现改为平面宣纸底、水墨贴片、少量立体地标。保留六边形邻接，不按概念图随意跨节点连接。参考图的路线、地名和节点数量不是最终配置。

## 实现顺序

1. 独立样板区表现，平面地表覆盖原地形，不破坏已有 Terrain 数据；复用节点选择与棋子定位。
2. 拆出无文字山石、竹林、村落、山门贴片；节点名称和线路由现有系统绘制，不能把整张概念图当作可交互地图。
3. 地标避让节点和连线，棋子始终可见；采用图集、实例化及区域显隐，检查渲染开销。
4. 在框架表中补入样板区关卡、奖励与文本，接现有剧情和原生战斗。
5. 验证出生到汇合的可玩流程、两路线收益差异、改命救人和历史角色自动选项。

## 验收

- 常用缩放下节点、连线和所有存活棋子清楚。
- 山石贴片不遮挡点击，不产生原地形穿插。
- 玩家能从出生点玩到天选路线，并作出至少一次路线及时间取舍。
- 单次宝藏、历史改命、后台战斗和存档恢复沿用原有规则。
- 比较同视角开启/关闭装饰时的 Batches、SetPass 与帧耗时，再决定扩图。
